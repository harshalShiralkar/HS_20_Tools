# 🚀 HS 20 Tools

**HS 20 Tools** is a powerful, high-performance web utility platform built for developers, designers, students, and professionals. It provides 20+ essential digital tools directly inside your web browser with absolute privacy and zero server uploads.

🌐 **Live Website:** [https://hs20tools.onrender.com](https://hs20tools.onrender.com)

---

## ✨ Key Features & Tools Included

### 🖼️ Image Utilities
1. **Image Compressor** – Reduce file sizes instantly with customizable quality sliders.
2. **Image Format Converter** – Convert between PNG, JPEG, and WEBP formats.
3. **Image Resizer** – Resize dimensions precisely with aspect ratio locking.
4. **Image Cropper** – Crop custom image regions on the fly.
5. **Image to PDF** – Compile multiple images into a single downloadable PDF document.

### 📄 PDF Suite
6. **PDF Merge** – Combine multiple PDF files into one master document.
7. **PDF Split** – Extract specific page ranges into new PDFs.
8. **PDF Compressor** – Optimize document file sizes client-side.
9. **PDF to JPG** – Render PDF pages into high-resolution JPG images.

### 📱 QR & Barcode Tools
10. **QR Generator** – Generate high-density customizable QR codes.
11. **QR Scanner** – Decode QR codes from uploaded image files.
12. **Barcode Generator** – Create 1D linear barcodes (Code128, EAN).

### 📝 Text & Developer Utilities
13. **Word Counter** – Real-time count of words, characters, sentences, and reading time.
14. **Case Converter** – Transform text to UPPERCASE, lowercase, Title Case, or camelCase.
15. **JSON Formatter & Validator** – Prettify, minify, and validate JSON syntax live.
16. **Base64 Converter** – Encode and decode strings/files to and from Base64.
17. **URL Encoder** – Safely encode and decode URL parameters.
18. **Password Generator** – Generate cryptographically random secure passwords.

### 🧮 Calculators
19. **Age Calculator** – Calculate exact years, months, days, and birthday countdowns.
20. **GST Calculator** – Calculate Indian Goods and Services Tax (inclusive/exclusive breakdown).

---

## 🔒 Privacy First Architecture
All operations—including PDF manipulation, image conversions, and code parsing—execute **100% client-side** in your browser memory using modern JavaScript and CDN libraries (`pdf-lib`, `pdf.js`, `jsQR`, `JsBarcode`). **Your files never leave your device and are never stored on any remote server.**
